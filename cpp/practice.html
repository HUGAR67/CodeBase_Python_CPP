P01 入門

計算總和

讀入一個整數 N，接著讀入 N 個整數，輸出這些數字的總和。

輸入說明

第一行為 N；第二行有 N 個整數。

輸出說明

輸出一個整數，代表總和。

範例輸入

5
1 2 3 4 5

範例輸出

15

能力重點：練習 cin、for 迴圈與累加。

解題思路

先讀取 N，再讀取 N 個整數並累加。使用 long long 可容納較大的總和。

參考答案（C++） 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    long long total = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        total += x;
    }

    cout << total << "\n";
    return 0;
}

P02 入門

奇偶統計

讀入 N 個整數，分別計算偶數與奇數的數量。

輸入說明

第一行為 N；第二行有 N 個整數。

輸出說明

輸出「偶數個數 奇數個數」。

範例輸入

6
1 2 3 4 5 6

範例輸出

3 3

能力重點：練習 %、if 與計數器。

解題思路

逐一讀入數字，依照 x % 2 是否為 0，分別增加偶數或奇數計數器。

參考答案（C++） 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int even = 0, odd = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x % 2 == 0) even++;
        else odd++;
    }

    cout << even << " " << odd << "\n";
    return 0;
}

P03 入門～初階

找最大值

讀入 N 個整數，輸出其中最大的數字。請勿使用額外排序。

輸入說明

第一行為 N；第二行有 N 個整數。

輸出說明

輸出最大值。

範例輸入

5
-3 8 2 7 1

範例輸出

8

能力重點：練習陣列走訪、比較與更新答案。

解題思路

讀入第一個數字作為最大值，接著比較剩餘數字；不需要排序。

參考答案（C++） 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int x;
    cin >> x;
    int maximum = x;

    for (int i = 1; i < n; i++) {
        cin >> x;
        if (x > maximum) maximum = x;
    }

    cout << maximum << "\n";
    return 0;
}

P04 初階

成績等第

讀入一個 0 到 100 的整數分數。90 分以上為 A，80–89 為 B，70–79 為 C，60–69 為 D，其餘為 F。

輸入說明

一個整數 score。

輸出說明

輸出對應等第 A、B、C、D 或 F。

範例輸入

86

範例輸出

B

能力重點：練習 if / else if / else 與邊界條件。

解題思路

從最高分開始用 if / else if 判斷，確保每個分數只輸出一個等第。

參考答案（C++） 
#include <iostream>
using namespace std;

int main() {
    int score;
    cin >> score;

    if (score >= 90) cout << "A";
    else if (score >= 80) cout << "B";
    else if (score >= 70) cout << "C";
    else if (score >= 60) cout << "D";
    else cout << "F";

    cout << "\n";
    return 0;
}

P05 初階

數字各位數總和

讀入一個非負整數 N，輸出它每一位數字相加的結果。請使用迴圈完成。

輸入說明

一個非負整數 N。

輸出說明

輸出各位數字總和。

範例輸入

5082

範例輸出

15

能力重點：練習 while、整數除法與取餘數。

解題思路

% 10 取得個位數，/ 10 去除個位數。當 n 變成 0 時，所有位數就都處理完了。

參考答案（C++） 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int total = 0;
    while (n > 0) {
        total += n % 10;
        n /= 10;
    }

    cout << total << "\n";
    return 0;
}

P06 初階

連續累加直到 0

持續讀入整數，遇到 0 時停止；輸出之前所有非 0 整數的總和。

輸入說明

每行一個整數，最後以 0 結束。

輸出說明

輸出總和，不包含結束用的 0。

範例輸入

3
-2
7
0

範例輸出

8

能力重點：練習 while 與停止條件。

解題思路

持續讀入整數；讀到 0 就 break，否則加到 total。

參考答案（C++） 
#include <iostream>
using namespace std;

int main() {
    int x;
    int total = 0;

    while (cin >> x && x != 0) {
        total += x;
    }

    cout << total << "\n";
    return 0;
}

P07 初階

統計出現次數

讀入 N 個整數和目標值 X，輸出 X 在這 N 個整數中出現幾次。

輸入說明

第一行 N；第二行 N 個整數；第三行 X。

輸出說明

輸出出現次數。

範例輸入

7
2 1 2 3 2 4 5
2

範例輸出

3

能力重點：練習陣列走訪與計數。

解題思路

讀入 N 個數字，再讀目標值 X。每次發現相等的數字就將 count 加一。

參考答案（C++） 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    int count = 0;
    int* nums = new int[n];
    for (int i = 0; i < n; i++) cin >> nums[i];

    int x;
    cin >> x;
    for (int i = 0; i < n; i++) {
        if (nums[i] == x) count++;
    }

    cout << count << "\n";
    delete[] nums;
    return 0;
}

P08 進階入門

由小到大排序

讀入 N 個整數，將它們由小到大輸出。請先嘗試自行實作選擇排序或泡沫排序。

輸入說明

第一行 N；第二行 N 個整數。

輸出說明

由小到大輸出，數字以空白分隔。

範例輸入

5
4 1 5 2 3

範例輸出

1 2 3 4 5

能力重點：APCS 基礎常見能力：巢狀迴圈、比較與交換。

解題思路

泡沫排序比較相鄰元素，若前面比後面大就交換。每一輪會將最大未排序值推到右側。

參考答案（C++） 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) cin >> nums[i];

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (nums[j] > nums[j + 1]) {
                int temp = nums[j];
                nums[j] = nums[j + 1];
                nums[j + 1] = temp;
            }
        }
    }

    for (int i = 0; i < n; i++) {
        if (i > 0) cout << " ";
        cout << nums[i];
    }
    cout << "\n";
    return 0;
}
