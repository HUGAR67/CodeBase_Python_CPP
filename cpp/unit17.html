pair、tuple 與自訂排序

pair 可把兩個關聯值綁在一起，例如姓名與分數、起點與終點。

🎯 本單元學習目標

  • 說明「pair、tuple 與自訂排序」在解題時能處理哪一類問題。
  • 讀懂範例中的輸入、處理流程與輸出結果。
  • 能修改範例，並用至少兩組測資驗證自己的理解。

一、先建立觀念

自訂比較函式決定排序規則。分數不同時由高到低，同分時姓名字典序由小到大。

解題習慣：先確認輸入有哪些、輸出需要什麼，再決定資料要如何保存，以及每一步要做什麼。不要一看到題目就急著打程式。

二、範例程式

先試著自己預測輸出，再複製到線上編輯器執行。觀察每個變數在程式執行前後的變化。

#include <algorithm>
#include <iostream>
#include <string>
#include <vector>
using namespace std;
int main() {
    vector<pair<string, int>> a = {{"Amy", 90}, {"Ben", 82}, {"Cody", 90}};
    sort(a.begin(), a.end(), [](auto x, auto y) {
        if (x.second != y.second) return x.second > y.second;
        return x.first < y.first;
    });
    for (auto p : a) cout << p.first << " " << p.second << "\n";
}

三、執行結果與逐步理解

Amy 90
Cody 90
Ben 82
  1. 讀取／準備資料：確認程式中哪些值是固定的，哪些值可能來自輸入。
  2. 執行主要步驟：追蹤迴圈、條件或函式的執行順序，不要只看最後一行。
  3. 輸出答案：確認空格、換行、資料型態與題目要求一致。

四、常見錯誤與除錯

容易踩到的坑：比較函式要形成一致的嚴格弱序；不要在同等元素之間互相判定小於。

如果結果不對，可以依序檢查：① 讀到的資料是否正確；② 邊界條件是否漏掉；③ 迴圈是否多跑／少跑一次；④ 輸出格式是否完全符合題目。
