圖論：圖的表示與 BFS/DFS

圖可以用鄰接串列表示；BFS 找無權圖最短距離，DFS 常用於連通性與遍歷。

🎯 本單元學習目標

  • 說明「圖論：圖的表示與 BFS/DFS」在解題時能處理哪一類問題。
  • 讀懂範例中的輸入、處理流程與輸出結果。
  • 能修改範例，並用至少兩組測資驗證自己的理解。

一、先建立觀念

BFS 使用 queue；第一次抵達某個頂點時得到無權圖的最短邊數距離。dist=-1 代表尚未走訪。

解題習慣：先確認輸入有哪些、輸出需要什麼，再決定資料要如何保存，以及每一步要做什麼。不要一看到題目就急著打程式。

二、範例程式

先試著自己預測輸出，再複製到線上編輯器執行。觀察每個變數在程式執行前後的變化。

#include <iostream>
#include <vector>
#include <queue>
using namespace std;
int main() {
    vector<vector<int>> g = {{1,2},{0,3},{0,3},{1,2}};
    vector<int> dist(4, -1); queue<int> q;
    dist[0] = 0; q.push(0);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : g[u]) if (dist[v] == -1) { dist[v] = dist[u] + 1; q.push(v); }
    }
    for (int d : dist) cout << d << " ";
}

三、執行結果與逐步理解

0 1 1 2
  1. 讀取／準備資料：確認程式中哪些值是固定的，哪些值可能來自輸入。
  2. 執行主要步驟：追蹤迴圈、條件或函式的執行順序，不要只看最後一行。
  3. 輸出答案：確認空格、換行、資料型態與題目要求一致。

四、常見錯誤與除錯

容易踩到的坑：無向邊要加 u→v 與 v→u；有向圖則依題意決定方向。

如果結果不對，可以依序檢查：① 讀到的資料是否正確；② 邊界條件是否漏掉；③ 迴圈是否多跑／少跑一次；④ 輸出格式是否完全符合題目。
