數論工具：最大公因數與質數

數論題常出現在競賽中，先掌握最大公因數、最小公倍數與質數判斷。

🎯 本單元學習目標

  • 說明這個主題在解題時能處理哪一類問題。
  • 讀懂範例的資料、處理流程與輸出結果。
  • 能修改範例，並用多組測資驗證自己的理解。

一、先建立觀念

輾轉相除法反覆把 (a, b) 換成 (b, a % b)，直到 b 為 0。最小公倍數可用 a / gcd(a,b) * b 計算，先除再乘可降低溢位風險（C++ 特別重要）。

解題習慣：先確認輸入、輸出與限制，再決定資料結構與演算法；不要只因為程式碼短就認為它一定正確。

二、範例程式

先預測輸出，再複製到線上編輯器執行，觀察每個變數的變化。

import math

def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a

def lcm(a, b):
    return a // gcd(a, b) * b

print(gcd(24, 18))
print(lcm(24, 18))
print([n for n in range(2, 20) if all(n % d != 0 for d in range(2, math.isqrt(n) + 1))])

四、常見錯誤與除錯

容易踩到的坑：質數判斷只需要檢查到平方根；1 不是質數，0 與負數也需要依題目定義處理。

測試時至少包含一般資料、最小值、最大值、重複資料與沒有答案的情況。若結果不對，先用小資料手算流程。

五、動手練習

APCS PRACTICE

挑戰任務

輸入兩個正整數，輸出最大公因數與最小公倍數；再試著判斷一個數是否為質數。

看提示

先用紙筆手算小測資，定義每個變數的意義，再逐步寫出流程。完成後試著解釋為什麼你的方法一定涵蓋所有情況。

  • 能不看範例寫出基本版本。
  • 能解釋演算法如何處理邊界情況。
