位元運算與 APCS 綜合訓練

位元運算直接操作整數的二進位表示；這是進階工具，先理解常用符號，再練習綜合題的拆解。

🎯 本單元學習目標

  • 說明這個主題在解題時能處理哪一類問題。
  • 讀懂範例的資料、處理流程與輸出結果。
  • 能修改範例，並用多組測資驗證自己的理解。

一、先建立觀念

& 是位元 AND。2 的冪次在二進位中只有一個 1，因此 n & (n-1) 會把那個 1 清掉，結果為 0。這個技巧很精簡，但要先確定 n 是正數。

解題習慣：先確認輸入、輸出與限制，再決定資料結構與演算法；不要只因為程式碼短就認為它一定正確。

二、範例程式

先預測輸出，再複製到線上編輯器執行，觀察每個變數的變化。

def is_power_of_two(n):
    return n > 0 and (n & (n - 1)) == 0

for n in [1, 2, 3, 4, 8, 12, 16]:
    print(n, is_power_of_two(n))

四、常見錯誤與除錯

容易踩到的坑：位元技巧不應只背公式；要先理解二進位變化，並特別處理 0、負數與資料型態範圍。

測試時至少包含一般資料、最小值、最大值、重複資料與沒有答案的情況。若結果不對，先用小資料手算流程。

五、動手練習

APCS PRACTICE

挑戰任務

完成一題 APCS 風格綜合練習：讀入一串整數，輸出最長連續遞增區間長度，並測試空間不足、全相同與完全遞增的資料。

看提示

先用紙筆手算小測資，定義每個變數的意義，再逐步寫出流程。完成後試著解釋為什麼你的方法一定涵蓋所有情況。

六、本單元小結

  • 能用自己的話說明核心概念。
  • 能不看範例寫出基本版本。
  • 能解釋演算法如何處理邊界情況。
