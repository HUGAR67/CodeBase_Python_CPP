Python 基礎 · UNIT 09

串列 list

list 可以保存多筆資料，並支援新增、修改、排序與逐一走訪。

🎯 本單元學習目標

  • 說明「串列 list」在解題時能處理哪一類問題。
  • 讀懂範例中的輸入、處理流程與輸出結果。
  • 能修改範例，並用至少兩組測資驗證自己的理解。

一、先建立觀念

append() 加到尾端；sort() 會直接改變原串列；sorted(nums) 則回傳排序後的新串列。

解題習慣：先確認輸入有哪些、輸出需要什麼，再決定資料要如何保存，以及每一步要做什麼。不要一看到題目就急著打程式。

二、範例程式

先試著自己預測輸出，再複製到線上編輯器執行。觀察每個變數在程式執行前後的變化。

nums = [8, 3, 10, 3]
nums.append(6)
print(nums)
print(max(nums), min(nums), sum(nums))
nums.sort()
print(nums)

三、執行結果與逐步理解

[8, 3, 10, 3, 6]
10 3 30
[3, 3, 6, 8, 10]
  1. 讀取／準備資料：確認程式中哪些值是固定的，哪些值可能來自輸入。
  2. 執行主要步驟：追蹤迴圈、條件或函式的執行順序，不要只看最後一行。
  3. 輸出答案：確認空格、換行、資料型態與題目要求一致。

四、常見錯誤與除錯

容易踩到的坑：空串列不能直接用 nums[0]；先確認資料筆數大於 0。

如果結果不對，可以依序檢查：① 讀到的資料是否正確；② 邊界條件是否漏掉；③ 迴圈是否多跑／少跑一次；④ 輸出格式是否完全符合題目。

五、動手練習

TRY IT

挑戰任務

讀入 n 個數字，輸出最大值、最小值與平均數。

建議測資：至少測試一般情況、最小輸入，以及容易出錯的邊界情況。

看提示（先自己想想再打開）

先用紙筆手算一組小測資。寫出每一步的重要變數，再把流程翻譯成程式；若有重複步驟，考慮使用迴圈或函式。

六、本單元小結

  • 能用自己的話說明本單元的核心概念。
  • 能不看範例，自己寫出基本版本。
  • 能設計測資檢查邊界情況，並解釋為什麼答案正確。
