P01入門

計算總和

讀入一個整數 N，接著讀入 N 個整數，輸出這些數字的總和。

輸入說明

第一行為 N；第二行有 N 個整數。

輸出說明

輸出一個整數，代表總和。

範例輸入

5
1 2 3 4 5

範例輸出

15

能力重點：練習 input、split、整數轉換與累加。

解題思路

使用 split() 讀取第二行，再逐一轉成整數並累加。N 表示有幾個數字。

參考答案（Python）
n = int(input())
nums = list(map(int, input().split()))

total = 0
for x in nums:
    total += x

print(total)

P02入門

奇偶統計

讀入 N 個整數，分別計算偶數與奇數的數量。

輸入說明

第一行為 N；第二行有 N 個整數。

輸出說明

輸出「偶數個數 奇數個數」。

範例輸入

6
1 2 3 4 5 6

範例輸出

3 3

能力重點：練習迴圈、條件判斷與計數器。

解題思路

每個數字除以 2 的餘數為 0 就是偶數，否則是奇數。分別用兩個計數器記錄。

參考答案（Python）
n = int(input())
nums = list(map(int, input().split()))

even = 0
odd = 0
for x in nums:
    if x % 2 == 0:
        even += 1
    else:
        odd += 1

print(even, odd)

P03入門～初階

找最大值

讀入 N 個整數，輸出其中最大的數字。不得直接使用 max()。

輸入說明

第一行為 N；第二行有 N 個整數。

輸出說明

輸出最大值。

範例輸入

5
-3 8 2 7 1

範例輸出

8

能力重點：練習走訪資料、比較與更新答案。

解題思路

先把第一個數字當成目前最大值，再逐一比較其他數字；遇到更大的就更新。

參考答案（Python）
n = int(input())
nums = list(map(int, input().split()))

maximum = nums[0]
for x in nums:
    if x > maximum:
        maximum = x

print(maximum)

P04初階

成績等第

讀入一個 0 到 100 的整數分數。90 分以上為 A，80–89 為 B，70–79 為 C，60–69 為 D，其餘為 F。

輸入說明

一個整數 score。

輸出說明

輸出對應等第 A、B、C、D 或 F。

範例輸入

86

範例輸出

B

能力重點：練習多層 if / elif / else 與邊界條件。

解題思路

由高分門檻開始判斷，因為第一個成立的條件就是該分數所屬的等第。

參考答案（Python）
score = int(input())

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("F")

P05初階

數字各位數總和

讀入一個非負整數 N，輸出它每一位數字相加的結果。請使用迴圈完成。

輸入說明

一個非負整數 N。

輸出說明

輸出各位數字總和。

範例輸入

5082

範例輸出

15

能力重點：練習 while、整數除法 // 與取餘數 %。

解題思路

每次用 % 10 取出最後一位，再用 // 10 去掉最後一位。輸入 0 時答案也是 0。

參考答案（Python）
n = int(input())
total = 0

while n > 0:
    total += n % 10
    n //= 10

print(total)

P06初階

連續累加直到 0

持續讀入整數，遇到 0 時停止；輸出之前所有非 0 整數的總和。

輸入說明

每行一個整數，最後以 0 結束。

輸出說明

輸出總和，不包含結束用的 0。

範例輸入

3
-2
7
0

範例輸出

8

能力重點：練習 while、停止條件與累加。

解題思路

每次讀一個數字，若是 0 就停止；否則加進總和。這題使用 EOF 前遇到 0 結束的輸入格式。

參考答案（Python）
total = 0

while True:
    x = int(input())
    if x == 0:
        break
    total += x

print(total)

P07初階

統計出現次數

讀入 N 個整數和目標值 X，輸出 X 在這 N 個整數中出現幾次。

輸入說明

第一行 N；第二行 N 個整數；第三行 X。

輸出說明

輸出出現次數。

範例輸入

7
2 1 2 3 2 4 5
2

範例輸出

3

能力重點：練習串列走訪與計數。

解題思路

逐一檢查每個數字，與目標 X 相同時就把計數器加一。

參考答案（Python）
n = int(input())
nums = list(map(int, input().split()))
x = int(input())

count = 0
for value in nums:
    if value == x:
        count += 1

print(count)

P08進階入門

排序前的準備

讀入 N 個整數，將它們由小到大輸出。請先嘗試自行實作選擇排序或泡沫排序。

輸入說明

第一行 N；第二行 N 個整數。

輸出說明

由小到大輸出，數字以空白分隔。

範例輸入

5
4 1 5 2 3

範例輸出

1 2 3 4 5

能力重點：APCS 基礎常見能力：多重迴圈、比較與交換。

解題思路

這裡示範泡沫排序。相鄰兩個數字若順序錯誤就交換；每一輪會把較大的數字往右推。

參考答案（Python）
n = int(input())
nums = list(map(int, input().split()))

for i in range(n):
    for j in range(0, n - 1 - i):
        if nums[j] > nums[j + 1]:
            nums[j], nums[j + 1] = nums[j + 1], nums[j]

print(*nums)
