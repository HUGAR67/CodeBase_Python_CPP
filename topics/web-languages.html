從零開始學網頁：HTML、CSS、JavaScript、JSON

把網頁想成一間店：HTML 決定店裡有什麼，CSS 決定它長什麼樣，JavaScript 負責互動，JSON 則是常用來整理與交換資料的格式。這些例子可以直接在瀏覽器閱讀與操作，不用安裝軟體。

HTML CSS JavaScript JSON 綜合練習

1. HTML：網頁的骨架

HTML 使用標籤描述內容，例如標題、段落、圖片和按鈕。大部分標籤由開始標籤與結束標籤組成。

<h1>我的第一個網頁</h1>
<p>這是一段介紹文字。</p>
<button>按我</button>

逐行看： <h1> 是主要標題；<p> 是段落；<button> 是按鈕。HTML 負責結構，不是主要用來控制顏色。

即時預覽

我的第一個網頁

這是一段介紹文字。

按鈕尚未被點擊。

2. CSS：網頁的外觀

CSS 控制顏色、字型、間距、邊框與排版。選擇器決定要修改哪個 HTML 元素。

h1 {
  color: rebeccapurple;
  font-size: 32px;
}
.card {
  padding: 16px;
  border-radius: 12px;
}

逐行看： h1 選取標題；大括號內是設定；color 是文字顏色；padding 是內容與邊界之間的留白；border-radius 讓角落變圓。

CSS 可以改變我的顏色

你選擇顏色後，標題會立即更新。

3. JavaScript：讓網頁動起來

JavaScript 可以回應點擊、讀取輸入、計算資料並更新畫面。這是瀏覽器能直接執行的程式語言。

const button = document.querySelector("#helloButton");
button.addEventListener("click", () => {
  document.querySelector("#helloResult").textContent = "你好！按鈕成功執行了。";
});

逐行看： querySelector 找到 HTML 元素；addEventListener("click", ...) 設定點擊時要做的事；textContent 修改畫面上的文字。

按下按鈕，這段文字就會改變。

4. JSON：整理資料的格式

JSON 常用來保存或傳送資料。它看起來像 JavaScript 物件，但 JSON 格式的鍵和值字串都必須使用雙引號；不能直接放函式或註解。

{
  "name": "Mina",
  "language": "JavaScript",
  "completedLessons": 3,
  "likesCoding": true
}

逐行看： name、language 是欄位名稱；文字要用雙引號；3 是數字；true 是布林值。實際資料檔常見副檔名是 .json。

按下按鈕後，會顯示整理好的資料。

5. 綜合練習：四者如何合作？

  1. HTML 建立標題、輸入框和按鈕。
  2. CSS 把內容排整齊、調整顏色與間距。
  3. JavaScript 在使用者點擊時讀取輸入並更新結果。
  4. JSON 可以用來整理一組課程、題目或設定資料。

如果想做網站，HTML 和 CSS 是基礎，JavaScript 負責互動，JSON 常用於資料交換。它們用途不同，但通常會一起出現在同一個專案中。CodeBase 本身就使用 HTML、CSS 和 JavaScript，GitHub Pages 負責把靜態檔案發布到網路上。
