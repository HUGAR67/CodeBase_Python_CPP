資訊安全入門：保護帳號、裝置與資料

從日常生活常見的風險開始，學習辨識釣魚訊息、保護帳號、更新裝置與負責任地處理資安問題。

🎯 學完你可以

  • 認識資訊安全的機密性、完整性與可用性。
  • 辨識釣魚、社交工程、惡意軟體與不安全連線的風險。
  • 建立安全更新、備份、權限管理和多因素驗證的習慣。
  • 知道發現可疑事件時，如何安全地處理與回報。

一、什麼是資訊安全？

資訊安全（Information Security，常簡稱資安）是保護資料、裝置、帳號與服務，避免被未授權查看、修改、破壞或中斷。

🔒 機密性

只有被授權的人才能讀取資料，例如不把私人文件公開。

🧾 完整性

資料不應被未授權或不當地修改，例如確認下載檔案來源。

🟢 可用性

需要時能正常使用服務，例如保留備份與復原方式。

二、常見威脅與防範方式

釣魚與社交工程

攻擊者可能假冒學校、遊戲平台、銀行或熟人，利用急迫感誘使你點連結、交出密碼或提供驗證碼。不要只看顯示名稱；要檢查真正的網域、內容是否合理，並透過已知的官方管道確認。

惡意附件與假下載

不要隨便開啟陌生人寄來的附件或執行來路不明的程式。下載軟體時使用官方網站或可信的應用程式商店，並保持系統與防護軟體更新。

帳號遭盜用

每個重要服務使用不同密碼，開啟多因素驗證（MFA），不分享一次性驗證碼，也不要讓別人遠端操作你的帳號。

公共 Wi-Fi 與隱私

確認網站使用 HTTPS，但要記得 HTTPS 不代表網站本身一定可信。公共網路上不要忽略憑證警告，也不要在不可信裝置上儲存帳號密碼。

三、給初學者的資安習慣

  1. 使用獨一無二且足夠長的密碼，考慮使用可信的密碼管理器。
  2. 能開啟 MFA 的重要帳號就開啟，並安全保存復原碼。
  3. 定期更新作業系統、瀏覽器與常用軟體。
  4. 重要檔案保留至少一份獨立備份，並確認可以還原。
  5. 檢查應用程式要求的權限，不需要的就不要給。
  6. 不公開住址、學校班級、電話、驗證碼或其他不必要的個人資訊。
  7. 收到可疑訊息先停下來，使用官方網站或已知聯絡方式查證。

四、網站開發者也要注意什麼？

  • 不要把 API 金鑰、私鑰、密碼或真實使用者資料放進公開的 HTML／JavaScript。
  • 不要把使用者輸入直接當作 HTML 插入頁面；應使用安全的文字輸出方式並驗證輸入。
  • 只收集完成功能所必需的資料，並清楚說明資料用途。
  • 登入、權限和敏感資料處理不能只靠前端判斷；伺服器端也必須驗證。
  • 測試時使用自己建立的測試帳號與資料，避免接觸他人的私人資料。
安全界線：只在自己擁有或獲得明確授權的系統上測試。不要掃描、登入、猜密碼或修改他人系統；發現漏洞時，先停止測試並透過正式管道回報。

五、遇到可疑狀況怎麼做？

  1. 不要再點可疑連結或提供更多資料。
  2. 如果輸入了密碼，使用可信裝置前往官方網站更改密碼，並檢查其他登入工作階段。
  3. 啟用或重新檢查 MFA；若驗證碼或復原碼可能外洩，依服務官方指引處理。
  4. 保留必要的訊息與時間資訊，向平台、學校資訊人員或可信任的成年人求助。
  5. 若涉及金錢、威脅或個人資料外洩，盡快通知相關機構並尋求合適協助。
