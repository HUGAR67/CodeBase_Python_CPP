APCS 考場 Linux 操作入門

除了會寫程式，也要熟悉如何在 Linux 環境找檔案、開啟終端機、編譯、執行與測試程式。

🎯 學完你可以

  • 認識桌面、檔案管理員與終端機的用途。
  • 使用基本指令查看位置、列出檔案、切換資料夾。
  • 執行 Python 程式，或編譯並執行 C++ 程式。
  • 用輸入檔與輸出重導向測試程式，並知道常見錯誤怎麼查。
重要提醒：不同考場、年度與考試平台的作業系統、編輯器、可用指令及提交方式可能不同。請以當年度官方應試說明與現場規定為準；以下是通用 Linux 練習，不代表考場一定提供所有工具。

一、先認識三個地方

  • 桌面（Desktop）：開啟應用程式與檔案管理員。
  • 檔案管理員（Files）：用圖形介面瀏覽資料夾、建立資料夾、開啟程式碼檔。
  • 終端機（Terminal）：輸入文字指令，編譯、執行和測試程式。

如果考試環境提供圖形介面，通常可以從應用程式選單搜尋 Terminal／終端機；若介面不同，先閱讀現場指引，不要自行更改系統設定。

二、常用終端機指令

指令 用途 例子
pwd 顯示目前所在資料夾 pwd
ls 列出目前資料夾的檔案 ls
cd 資料夾 進入資料夾 cd Documents
cd .. 回到上一層資料夾 cd ..
mkdir practice 建立資料夾 mkdir practice
clear 清除終端機畫面 clear
小技巧：Linux 指令通常區分大小寫。main.cpp 和 Main.cpp 可能是兩個不同檔案。檔名有空格時，可用引號包住路徑。

三、執行 Python 程式

假設目前資料夾中有 main.py，可先確認檔案存在，再執行：

ls
python3 main.py

若程式需要輸入，執行後依提示輸入資料。若環境使用不同的 Python 指令，請依考場提供的版本與說明操作。

用輸入檔測試（選用）

若已建立 input.txt，可把檔案內容當作標準輸入：

python3 main.py < input.txt

四、編譯與執行 C++ 程式

假設檔名是 main.cpp，可用 g++ 編譯成可執行檔：

g++ main.cpp -std=c++17 -O2 -Wall -o main
./main
  • 第一行是編譯；若成功，會產生名為 main 的執行檔。
  • 第二行的 ./main 表示執行目前資料夾中的程式。
  • 若編譯器顯示錯誤，先看第一個錯誤訊息及行號，再回去檢查程式碼。

若使用輸入檔測試：

./main < input.txt

五、常見問題快速排查

找不到檔案：No such file or directory

先輸入 pwd 看目前位置，再用 ls 確認檔名是否拼對、大小寫是否一致；必要時用 cd 進入正確資料夾。

Permission denied

可能是權限或執行方式不對。對一般 g++ 編譯出的程式，請確認是在目前資料夾執行 ./main；不要在考場擅自更改系統權限，依現場規範處理。

程式一直等輸入

如果程式使用 input() 或 cin，它可能正在等待輸入。依題目格式輸入資料，或使用 < input.txt 重導向。

輸出多了提示文字

線上評測通常要求輸出格式完全符合題目。提交解題程式時，不要額外印出「請輸入數字」等提示，除非題目明確要求。

六、考前模擬流程

  1. 建立自己的練習資料夾，確認目前位置。
  2. 建立或開啟 main.py／main.cpp。
  3. 先用題目範例測試，再測試最小值、最大值與特殊情況。
  4. C++ 先編譯，再執行；Python 確認使用正確的直譯器指令。
  5. 最後確認輸出沒有多餘文字，檔名與提交方式符合規定。

七、動手練習

TRY IT

練習任務

  1. 用 pwd 顯示目前位置。
  2. 用 mkdir apcs-practice 建立練習資料夾，再用 cd apcs-practice 進入。
  3. 建立一個簡單的 Python 或 C++ 程式，輸出 Hello APCS。
  4. 成功執行後，試著用 input.txt 測試輸入重導向。
查看參考指令 
pwd
ls
mkdir apcs-practice
cd apcs-practice
# Python：python3 main.py
# C++：g++ main.cpp -std=c++17 -O2 -o main
# 執行 C++：./main

八、考場操作檢查清單

  • 知道如何開啟程式碼編輯器與終端機。
  • 知道目前檔案儲存在哪個資料夾。
  • 會執行 Python 或編譯 C++。
  • 會使用範例輸入測試，並檢查輸出格式。
  • 遇到錯誤先讀訊息，不慌張、不隨意更改系統設定。
  • 已閱讀當年度官方應試說明，了解考場允許使用的工具。
